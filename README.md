# Jump to Choose

เกมตอบคำถามเรื่อง **จำนวนเชิงซ้อนและหน่วยจินตภาพ (*i*)** ในรูปแบบสะพานกระจก ผู้เล่นต้องกระโดดข้ามแผ่นกระจกทีละแถว แต่ละแถวมี 2 แผ่น (A กับ B) ตอบถูกจะเหยียบได้ ตอบผิดกระจกแตกแล้วตกลงไป ข้ามให้ครบทุกแถวเพื่อไปรับ **Oak Cake Roll** ที่ปลายสะพาน

ตัวเกมเป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร และไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นตอนโหลดฟอนต์จาก Google Fonts)

## วิธีเล่น

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (Chrome, Safari หรือ Edge)
2. กด `SPACE` เพื่อเริ่ม
3. อ่านคำถามด้านบน แล้วเลือกแผ่นกระจก A หรือ B
4. กด `ENTER` เพื่อกระโดด
   - ตอบถูก: กระจกเป็นสีเขียว พร้อมคำอธิบายว่าทำไม
   - ตอบผิด: กระจกแตก ตัวละครตก แล้วกลับมาเริ่มที่แผ่นที่ปลอดภัยแผ่นล่าสุด
5. กด `SPACE` เพื่อไปข้อถัดไป
6. ข้ามครบทุกแถวแล้วจะได้เค้ก หน้าจบเกมจะบอกว่าทำกระจกแตกไปกี่ครั้ง

## ปุ่มควบคุม

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| `←` หรือ `A` | เลือกแผ่น A |
| `→` หรือ `B` | เลือกแผ่น B |
| `ENTER` | กระโดด |
| `SPACE` | เริ่มเกม / ไปข้อถัดไป |
| `R` | เริ่มใหม่ |
| `M` | เปิด/ปิดเสียง |
| `F` | เต็มจอ |

ใช้เมาส์ได้ด้วย คลิกแผ่นกระจก 1 ครั้งเพื่อเลือก คลิกซ้ำเพื่อกระโดด

## เนื้อหาในเกม

มีคำถามทั้งหมด 8 ข้อ ครอบคลุมเรื่อง

- ทำไมสมการ *x*² = −1 ไม่มีคำตอบเป็นจำนวนจริง
- รอบของกำลังของ *i* (*i*, −1, −*i*, 1 แล้ววนซ้ำ)
- หาค่า *i* ยกกำลังสูงๆ ด้วยการหารด้วย 4 แล้วดูเศษ เช่น *i*⁶, *i*¹¹, *i*⁵⁰
- ส่วนจริงและส่วนจินตภาพของ *z* = *a* + *bi* (รวมกรณีที่ส่วนจินตภาพติดลบ)

## แก้คำถามเอง

คำถามอยู่ใน `index.html` ตรงตัวแปร `QUESTIONS` (มีคอมเมนต์ `Questions: edit here` กำกับไว้) แต่ละข้อเขียนแบบนี้

```js
{ q: 'คำถาม', a: 'ตัวเลือก A', b: 'ตัวเลือก B', ans: 'b', why: 'เหตุผลที่แสดงหลังตอบ' },
```

- `ans` ใส่ `'a'` หรือ `'b'` ตามแผ่นที่ถูก
- เพิ่มหรือลบข้อได้เลย จำนวนแถวของสะพานจะเปลี่ยนตามจำนวนข้อเอง

## โครงสร้างไฟล์

```
jump-to-choose/
├── index.html        ตัวเกมทั้งหมด (HTML + CSS + JavaScript)
└── assets/
    ├── firefly.png   ตัวละครผู้เล่น
    └── cake.png      เค้กรางวัลที่ปลายสะพาน
```

## เทคนิคที่ใช้

- สะพาน 3 มิติทำด้วย CSS 3D transform (`perspective`, `rotateX`)
- ฉากหลังฝุ่นลอยและพลุกระดาษตอนชนะวาดด้วย `<canvas>`
- เสียงเอฟเฟกต์สร้างด้วย Web Audio API ในโค้ด · เสียงพากย์ Firefly อยู่ใน `assets/audio/` (ตัดจากคลิปเสียงรวม): เริ่มเกม `start-burn` · ตอบถูกสุ่ม `right-ignite` / `right-victory` / `right-mechanism` · ตอบผิด `wrong-terminated` · กลับขึ้นมาหลังตก `comeback` · ถึงเค้ก `rare-find` แล้วต่อด้วยเพลง `win-music` (楽音 - mosi mosi？ ช่วง 0:39–1:15) · เสียงพูดดัง 50% เพลง 25%
